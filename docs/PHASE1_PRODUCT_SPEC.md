# Phase 1 Product Spec: Niche AI Content Tool

## Selected First Product

**Name (working)**: LocalBiz AI Posts

**Description**: AI tool that generates a full month of social media posts (captions + hashtags + image prompts) for local small businesses (cafes, salons, gyms, clinics, etc.) based on their niche, location, and goals.

**Why this product**:
- Clear pain: local owners hate creating consistent content.
- Proven demand: similar tools (e.g. Marky) show real MRR.
- Easy to explain and sell.
- Can start as freemium or one-time + subscription.
- Complements digital products (prompt packs, templates).

## MVP Features (v0.1)

- Input: Business type, location, tone, goals.
- Output: 30 days of posts (text).
- Landing page with value prop, example, pricing.
- Simple backend or client-side for demo (API key later).

## Monetization Plan

- Free tier: limited generations.
- Pro: $29–$49/month or one-time packs.
- Later: white-label for agencies.

## Next Development Steps

1. Create landing page HTML/CSS.
2. Build simple generator UI.
3. Prepare example outputs.
4. Deploy via Vercel once ready.
